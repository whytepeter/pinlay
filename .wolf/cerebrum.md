## Key Learnings

- **Tailwind v4 + monorepo:** the app's CSS must include `@source "../../../../packages/design/src";` (in `apps/web/src/assets/main.css`). Tailwind v4 auto-detection skips node_modules, so classes used inside the `@pinlay/design` workspace package aren't generated without this — components render unstyled.
- **shadcn-vue install:** use the CLI from `packages/design` — `pnpm dlx shadcn-vue@latest add <comp> -y -o`. Requires `components.json` (no `tsx` key) + tsconfig `paths: { "@pinlay/design/*": ["./src/*"] }`. The latest registry imports icons from `@lucide/vue`; repoint those to `lucide-vue-next` after adding. Components import `cn` from `@pinlay/design/lib/utils` (exported in package.json `exports`).
- **Icons:** `@pinlay/design/src/components/Icon.vue` wraps `lucide-vue-next` (kebab `name` → PascalCase). Use `<Icon name="map-pin" />`.
