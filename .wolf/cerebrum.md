## Key Learnings

- **Tailwind v4 + monorepo:** the app's CSS must include `@source "../../../../packages/design/src";` (in `apps/app/src/assets/main.css`). Tailwind v4 auto-detection skips node_modules, so classes used inside the `@pinlayer/design` workspace package aren't generated without this — components render unstyled.
- **shadcn-vue install:** use the CLI from `packages/design` — `pnpm dlx shadcn-vue@latest add <comp> -y -o`. Requires `components.json` (no `tsx` key) + tsconfig `paths: { "@pinlayer/design/*": ["./src/*"] }`. The latest registry imports icons from `@lucide/vue`; repoint those to `lucide-vue-next` after adding. Components import `cn` from `@pinlayer/design/lib/utils` (exported in package.json `exports`).
- **Icons:** `@pinlayer/design/src/components/Icon.vue` wraps `lucide-vue-next` (kebab `name` → PascalCase). Use `<Icon name="map-pin" />`.

- [2026-05-26] Do not hand-roll buttons / pill toggles when a shadcn-vue primitive fits. Pane/section/segmented switchers → `Tabs`+`TabsList`+`TabsTrigger` (use `class="w-full"` on TabsList + `class="flex-1"` on TabsTrigger for full-width). Bind state with `v-model`. - [2026-05-26] Active nav item labels must NOT use `text-primary-foreground` on a transparent/sidebar background — `--primary-foreground` is WHITE (since accent is dark violet), which is invisible on the white sidebar in light mode. Use `text-foreground` for the active label (dark in light, light in dark — automatic). The accent color goes on the **icon** (`text-primary`) and/or the left accent bar, not the label.
- [2026-05-26] Responsive grid with a fixed `minmax(360px, 1fr)` overflows narrow viewports (cards extend past the container on mobile). Use `minmax(min(360px, 100%), 1fr)` so the column clamps to the container width when smaller than the requested minimum. Same fix applies to any `auto-fill`/`auto-fit` grid intended to be responsive.
